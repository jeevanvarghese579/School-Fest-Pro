Current issue:

* Schedule Generation & Export is missing many items.
* Not all registered items are appearing in the generated schedule.

Required behaviour:

A. Item Inclusion

* Every item that has at least one participant must be included in schedule generation.
* No eligible item should be skipped.
* Items with zero participants may be excluded.

B. Age Category Handling
When "Consider Age Categories" is enabled:

Treat each Item + Age Category combination as a separate schedule entry.

Example:

* Folk Song (Junior)
* Folk Song (Senior)
* Folk Song (Sub Junior)

must generate three separate schedule entries.

C. Group Items

* Group items must also be included in schedule generation.
* Group items must not be skipped.
* Group items should be scheduled using the same stage/day allocation logic.

D. Validation
Before generating the schedule:

Verify:

* Total items found
* Items with participants
* Individual items count
* Group items count

E. Debug Information
Add a Schedule Preview page showing:

* Total items considered
* Total schedule entries generated

* Item Name

4. Schedule Generation Reliability

The scheduling algorithm should:

* Process all eligible items before generating output.
* Never stop early due to conflicts.
* If a conflict cannot be avoided, still include the item in the schedule and add a remark explaining the conflict.
* Missing items are not acceptable.

Priority:

1. Include all eligible items.
2. Avoid clashes where possible.
3. Report unavoidable clashes in remarks.

5. Correct Time Calculation for Schedule Generation

Fix schedule duration calculation.

Each item must have a configurable field:

"Time required for one performance"

This should be entered in minutes.

During schedule generation, calculate total time required for each item using this formula:

Total Item Duration = Number of Participants × Time Required Per Performance

Examples:

* If an item has 10 participants and each performance takes 5 minutes:
  Total duration = 10 × 5 = 50 minutes

* If an item has 6 participants and each performance takes 3 minutes:
  Total duration = 6 × 3 = 18 minutes

Requirements:

* Use the actual number of participants registered for that item.
* If age categories are considered, calculate duration separately for each Item + Age Category group.
* If age categories are not considered, calculate duration using the total participants for that item.
* For group items, use the number of groups, not the number of individual students, when calculating duration.
* Add optional buffer time per item in General Settings.
* Final item duration should be:

Final Duration = (Participant Count × Time Per Performance) + Buffer Time

* Schedule start and end times must be calculated using this final duration.
* Exported schedule PDF must show:

  * Number of participants/groups
  * Time per performance
  * Buffer time
  * Total duration
  * Start time
  * End time

Important:
Do not assign fixed equal duration to all items unless the user has manually set the same time for all items.
Each item must calculate its own duration based on participant count.
